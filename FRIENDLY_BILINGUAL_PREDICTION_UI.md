# Friendly Bilingual Prediction UI

The Admin Prediction Center is designed for both technical and non-technical users.

## Language support
- English and Myanmar (မြန်မာ) switch is available directly on the Prediction Center page.
- The selected language is also synchronized with the existing i18next website language setting.
- Main explanations, buttons, result summaries, tables, statuses, and evaluation labels are bilingual.

## Simple View
The first view focuses on business meaning rather than model terminology:
- Next predicted value
- Average future prediction
- Expected trend (increasing / decreasing / stable)
- Easy model-quality status
- Actual vs predicted chart
- Likely low-to-high range
- Plain-language warning that forecasts are estimates

## Advanced Details
Technical information remains available for IT users, lecturers, and evaluation:
- MAE
- RMSE
- R²
- MAPE
- Baseline comparison
- Algorithm and selected model
- Train/test sizes
- Preprocessing counts

## Feedback Analysis
Shows a plain-language customer mood summary first, followed by positive/negative percentages, category breakdown, common themes, and consistency evaluation.

## Application Readiness
Shows a readiness score and simple guidance such as Ready for human review, More information needed, or Manual policy review needed. It does not make an automatic insurance approval or rejection decision.
